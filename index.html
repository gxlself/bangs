剪贴板

往下滚一直加载更早的记录，点一条放回剪贴板。macOS 直接读你的 Paste，Windows 自己记（密码管理器标记过的内容会跳过）。

暂存架

文件拖到刘海上先放着，换个窗口再拖出去。跨应用搬文件不用再找一块空桌面。

待办

输入一行，回车记下；做完点一下，字就散开飘走，不留已完成。这是刘海唯一会用键盘的地方，也只在输入框聚焦时才借。

下载

macOS

Apple 芯片 · macOS 12+
获取最新版

用 Developer ID 签了名并经过 Apple 公证，下载下来双击就能打开。

Windows

Windows 10 / 11 · 需要 WebView2
获取最新版

安装包没签名，SmartScreen 会拦一下，点「更多信息 → 仍要运行」。 装好后图标在右下角托盘里，右键能看到版本和设置。

全部版本和更新说明都在 Releases。 应用自己也会查：托盘菜单最底下那行就是当前版本，有新版会写「有新版本」，点一下跳到这里。

自己构建

git clone https://github.com/gxlself/bangs.git
cd bangs
pnpm install
pnpm tauri dev          # 开发
scripts/version.sh 0.2.0 # 改版本号（三个文件一起改）
scripts/build-release.sh # 打两端的安装包到 dist/release/

Tauri 2 + React + Rust。macOS 那侧用 NSPanel 贴在菜单栏之上，Windows 用窗口区域裁剪出刘海形状 — 两边都不抢焦点，点它不会打断你正在写的东西。
